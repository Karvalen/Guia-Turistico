# Turistando Roma

**Descubra Roma de um jeito fácil, acessível e divertido!**

## Sobre o projeto

O **Turistando Roma** é um site de turismo desenvolvido como parte de um trabalho escolar. Seu objetivo é apresentar informações sobre a cidade de Roma, na Itália, ajudando os visitantes a conhecer seus principais pontos turísticos, sua história e sua cultura.

O site foi pensado para ser **acessível, simples e fácil de navegar**, permitindo que diferentes pessoas encontrem informações de maneira prática.

## Objetivos

- Apresentar os principais pontos turísticos de Roma.
- Incentivar o turismo e o conhecimento cultural.
- Facilitar o acesso a informações sobre a cidade.
- Oferecer uma experiência de navegação simples e acessível.
- Aplicar conhecimentos de desenvolvimento web em um projeto escolar.

## O que você pode encontrar?

O site tem como proposta apresentar informações sobre lugares famosos de Roma, como:

- **Coliseu:** um dos monumentos mais conhecidos da Roma Antiga.
- **Fontana di Trevi:** uma famosa fonte histórica da cidade.
- **Basílica de São Pedro:** uma das construções religiosas mais famosas do mundo, localizada no Vaticano.

## Acessibilidade

A acessibilidade é um dos pontos importantes do Turistando Roma.

O projeto busca tornar a navegação mais simples e confortável, valorizando aspectos como:

- Organização clara das informações.
- Facilidade de navegação pelo site.
- Textos compreensíveis.
- Boa legibilidade do conteúdo.
- Uso de recursos visuais para facilitar a compreensão.

O objetivo é proporcionar uma experiência mais inclusiva para os visitantes.

## Tecnologias utilizadas

As tecnologias utilizadas no desenvolvimento do projeto podem incluir:

- **HTML:** estrutura das páginas.
- **CSS:** aparência e organização visual.
- **JavaScript:** interatividade e funcionalidades.


## Como acessar o projeto

1. Baixe ou clone os arquivos do projeto.
2. Abra a pasta do site.
3. Abra o arquivo `index.html` em um navegador.
4. Explore as informações e conheça os principais pontos turísticos de Roma.

## Finalidade educacional

Este projeto foi desenvolvido para um trabalho escolar, com o objetivo de praticar conhecimentos de criação de sites, organização de informações e desenvolvimento de uma interface acessível.

Além disso, o projeto permite explorar a história, a cultura e os pontos turísticos de uma das cidades mais famosas do mundo.
